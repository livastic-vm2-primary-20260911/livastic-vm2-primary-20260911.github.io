**What it does:** An original browser-local JS pure computation on a maximum 32KiB explicitly synthetic or anonymized JSON object, <=32 events and short alphabetic reference labels. It checks:
- Several payment labels claiming settlements for one logical buyer request (requires independent reconciliation before saying charged twice).
- A settlement *claim* but no delivery entry (may be log truncation or actual failure).
- A verification without settlement, or a delivery without recorded payment (does not prove theft).
- Latest quote vs claimed settlement amount, exact BigInt six-decimal USDC atomic values.
- Late retries of the same settled payment, replay rejections without payment proof and price changes requiring new buyer consent.
