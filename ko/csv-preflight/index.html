검사 범위와 결제 사실을 구분합니다

이 기능은 CSV의 일부 구조·품질 문제를 점검하는 도구이지 데이터베이스 반입 적합성, 내용의 의미상 정확성, 안전한 운영 반영, 규정 준수 인증을 보장하는 보안 감사가 아닙니다. 비밀키·개인정보·고객 기밀·지갑 복구 문구를 제출하지 마세요. 호스팅된 API는 제출한 데이터를 처리하므로 기밀 CSV에는 로컬 전용 도구를 이용하세요. 네트워크·지갑 비용은 구매자 부담일 수 있습니다.

해당 유료 API는 동일 실소유자가 VM5에서 운영하며 VM2의 이 페이지는 별도의 판매 안내 자료입니다. 외부 자동 검증 구매자가 이전에 가상 CSV 예시 GET을 실제 결제하고 결과를 받았으나, 구매자 입력 CSV POST의 독립적인 실결제는 아직 확인되지 않았습니다. 정기 구독·구매자 수·수익 보장은 주장하지 않습니다.

결제 통화는 Base 체인 eip155:8453의 정품 Circle USDC입니다. 결제 여부는 호환되는 x402 구매자 도구가 별도로 승인합니다. 무료 샘플, 이 웹페이지 열람, HTTP 402 응답은 실제 입금이 아닙니다.
