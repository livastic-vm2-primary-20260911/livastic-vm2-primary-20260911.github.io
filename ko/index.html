03 / 작업 절차

업무 범위를 정하고
근거를 납품합니다.

무료 검사에는 결제가 필요 없으며, 상담 신청만으로 계약이나 접근 허가가 성립하지 않습니다.

01

공개 가능한 범위 설명

공개 저장소 링크, 문제 상황, 기대 결과, 답장 이메일만 전달하세요. 비밀번호, API 키, 비공개 YAML은 문의 폼에 보내지 마세요.

02

검수 기준·결제 조건 합의

파일 수, 요청 작업, 납기, 검수 기준, 결제·예치금 확인 방법을 먼저 협의합니다. 승인을 받지 않은 자료에는 접근하지 않습니다.

03

검증 가능하게 납품

확인 가능한 발견 위치, 보고서, 수정 제안이나 합의된 코드를 제공합니다. 실제 저장소 환경에서의 재검토는 의뢰자에게 필요합니다.

04 / 자발적인 상담 신청

GitHub Actions에
점검이 필요하신가요?

Google Forms에는 답장 이메일과 민감하지 않은 작업 요약만 작성할 수 있습니다. 이 폼 자체로 비용 결제나 계약, 비공개 저장소 접근 승인이 발생하지 않습니다.
