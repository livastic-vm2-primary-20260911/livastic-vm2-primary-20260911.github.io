AI 에이전트용 정밀 검사가 필요하다면?

같은 소유자의 별도 VM5 서비스에서 32 KiB 이하의 허가된 민감하지 않은 CSV를 POST로 구조 분석합니다. 호출당 Base(eip155:8453) 정품 Circle USDC 0.005이며, 구매자가 x402로 따로 결제해야 합니다.

개인정보, 고객 원장, 의료·금융 기록, 보안 키·비밀정보를 외부 유료 API로 보내지 마세요. 민감한 내용은 무료 로컬 검사만 이용하세요.

실제 x402 결제 절차 보기 ↗ 무료 가상 서버 결과 보기 ↗ 동일 소유자 VM5의 별도 정식 지갑 결제 페이지 ↗

POST /v1/csv-preflight. HTTP 402는 판매가 아닌 결제 견적입니다. 무료 검사는 절대로 업로드하지 않습니다. 두 동의란과 결제 클릭 후 가상 CSV로 견적을 받고 구매자 지갑에 0.005 USDC EIP-3009 서명을 요청합니다. 실제 CSV는 서명 완료 후에만 VM5에 한 번 전송합니다. 개인키를 수집하지 않으며 자동 결제·가입·재시도는 없습니다. 정산이 불확실하면 재서명하지 말고 지갑을 확인하세요. 실제 정산금은 VM2 웹사이트가 아닌 VM5 운영자가 받습니다.

무료와 유료의 차이

무료 • 브라우저 내부

열 개수, 따옴표 구문, 중복 헤더·행, 빈 셀, 수식 의심값, 행 번호, 원문 없는 JSON 결과. 실제 가져오기 성공을 보증하는 검사가 아닙니다.

유료 • 별도 x402 API

구매자가 승인한 HTTP POST에 더 상세한 행·열 통계, 중복/빈 값/형식 의심값과 수식 경고를 JSON으로 반환합니다. 서버 처리이므로 비공개 CSV에는 적합하지 않습니다.

AI 보조 개발 사실을 공개하는 단일 소유자의 도구입니다. VM2는 무료 웹사이트, VM5는 별도 유료 API 운영자입니다. 과거 외부 결제는 다른 가상 CSV GET 상품에 한정되며 구매자 입력 POST의 독립 실결제는 아직 0건입니다. 허위 리뷰나 수입은 주장하지 않습니다.
